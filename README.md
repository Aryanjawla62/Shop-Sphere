# 🛒 ShopSphere – E-Commerce Website (Frontend)

ShopSphere is a modern, responsive **frontend e-commerce website** built using **HTML, CSS, and JavaScript**.  
It demonstrates real-world shopping cart functionality and clean UI design without using any framework.



## 🧠 Features
- Responsive landing page
- Dynamic product listing using JavaScript
- Add to Cart functionality
- Quantity management
- Cart data stored using LocalStorage
- Total price calculation
- Clean and scalable folder structure



## 🛠️ Tech Stack
- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, reusable components
- **JavaScript (ES6)** – DOM manipulation, events, logic
- **LocalStorage** – Persistent cart data
- **GitHub Pages** – Hosting
